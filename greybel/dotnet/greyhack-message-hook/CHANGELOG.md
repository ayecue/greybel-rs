# GreyHackMessageHook

## 2.0.0 · 2026-11-18

- The first release built from greybel-rs. The plugin speaks the generated `greyhack` duplex protocol, listens on `127.0.0.1:7777` by default (BepInEx `General.Port`), and provides in-game file deployments, builds, script contexts and debugging.
- Builds for BepInEx 5 (`GreyHackMessageHook5.dll`) and BepInEx 6 (`GreyHackMessageHook.dll`).
