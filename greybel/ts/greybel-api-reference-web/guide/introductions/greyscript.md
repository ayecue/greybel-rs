Grey Hack uses GreyScript, a dynamically typed scripting language derived from [MiniScript](https://miniscript.org/), for programs written and executed inside the game. This guide documents GreyScript's lexical structure, values, expressions, statements, functions, prototype-based inheritance, and runtime behavior. It also covers the syntax and development tools provided by Greybel.

The API reference documents the functions and game objects available to a program. Language chapters link to relevant reference entries; [GreyScript programs](#guide-greyscript) explains arguments, input, imports, and access to the game.

Programs can be written in Grey Hack's CodeEditor or with Greybel's [Visual Studio Code extension](https://marketplace.visualstudio.com/items?itemName=ayecue.greybel-vs), `greybel` command-line interface, and [web editor](https://editor.greyscript.org). Greybel executes programs in a simulated Grey Hack environment and builds source for the game; see [Tools](#guide-tools).

Example programs are available on [greyrepo.xyz](https://www.greyrepo.xyz/) and [GitHub](https://github.com/search?q=grey+hack).
